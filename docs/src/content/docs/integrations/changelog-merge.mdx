[changelog-merge](https://github.com/cachix/changelog-merge) merges Keep a Changelog
files semantically. Independent changelog entries from different branches are
combined, while incompatible edits produce Git conflict markers.

Enable the integration to install the nixpkgs package, configure Git's merge
driver, and select it for `CHANGELOG.md` inside the devenv shell, including when
activated through direnv:

```nix title="devenv.nix"
{
  changelog-merge.enable = true;
}
```

The integration uses [`git.config` and `git.attributes`](/git/)
and leaves repository and global Git configuration files untouched. Repository
`.gitattributes` and `.git/info/attributes` rules take precedence over its attributes.
You can override the executable with `changelog-merge.package` and add patterns for
other changelogs with `git.attributes`:

```nix title="devenv.nix"
{
  changelog-merge.enable = true;
  git.attributes = [ "packages/*/CHANGELOG.md merge=changelog-merge" ];
}
```

Your nixpkgs input must include `pkgs.changelog-merge`. If your pin predates the
package, update it or select a newer nixpkgs input in `devenv.yaml`.

Verify the configuration inside `devenv shell`:

```sh
git check-attr merge -- CHANGELOG.md
git config --get merge.changelog-merge.driver
```

Git uses the driver for merges, rebases, and cherry-picks that require three-way
merging. Each contributor and CI job needs the configured environment. Git commands
outside it and hosted web merges on GitHub or GitLab do not use this driver.
