# Repository instructions

Follow [CONTRIBUTING.md](CONTRIBUTING.md) and the
[design maintenance contract](docs/design/README.md) for every change and PR.
Before task completion, update relevant diagram source or meaningful provenance,
map implementation paths to those updates, render changed views, and obtain
independent review of the final commits. Reviewers must compare actual final code
with states, edges, owners and captions; CI cannot establish semantic fidelity.
Preserve existing repository test/build conventions and unrelated changes.
